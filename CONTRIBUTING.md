## 🤝 How to Contribute

We’re always open to contributions! Here’s how you can get started:

1. **Fork the repository**  
   Clone the repo to your local machine by clicking on "Fork" at the top of the page.
   
2. **Create a new branch**  
   Create a new branch to work on your feature/bugfix.  
   ```bash
   git checkout -b your-branch-name
