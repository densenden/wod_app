# 🚀 User Journeys: Dynamic WOD & Signage System  

## 🏋️ User Journey: Gym Owner (Basic WOD Display)  
**Goal:** Display daily workouts on a big screen without any technical knowledge.  

### 🔹 Step 1: Discovering the Solution  
- Gym owner struggles to present structured workouts professionally.  
- Searches for a simple solution and finds the **Studio Sen WOD Display** app in the App Store.  

### 🔹 Step 2: Setting Up the Gym Display  
- Installs the app and **creates a gym profile**.  
- **Adds daily workouts** (manually or imports them from a template).  
- The app **formats the content automatically** for optimal readability.  

### 🔹 Step 3: Displaying Workouts on a Smart TV  
- On the Smart TV, opens a browser and **loads the unique gym URL**.  
- Activates **fullscreen mode** for a seamless display.  
- Each day, the content updates **automatically** with no extra effort.  

---

## 🤸‍♂️ User Journey: Athlete (Accessing Workouts)  
**Goal:** Quickly check workout details on a personal device.  

### 🔹 Step 1: Scanning the QR Code  
- Athlete enters the gym and **scans the QR code** displayed on the screen.  
- Redirected to a **mobile-friendly workout page**.  

### 🔹 Step 2: Exploring Workout Details  
- Workout structure is clearly displayed on their phone.  
- Can **toggle details** (e.g., exercise explanations, weights, modifications).  
- Has the option to **download the app** for future access.  

---

## 🏢 User Journey: Studio Sen Signage (Advanced Template System)  
**Goal:** Use the system for broader signage needs beyond WODs.  

### 🔹 Step 1: Creating a Signage Display  
- User visits **Studio Sen Signage** website.  
- Selects a **pre-made template** (e.g., gym schedules, event boards, wayfinding).  

### 🔹 Step 2: Editing & Customizing Content  
- User **enters text and optional images** directly into the editor.  
- System **formats everything automatically** for a perfect layout.  
- Preview feature ensures the design looks professional.  

### 🔹 Step 3: Publishing & Displaying the Signage  
- User generates a **unique display URL**.  
- Opens the URL on **any Smart TV, tablet, or display screen**.  
- Content updates in **real-time** whenever edits are made.  

---

💡 **This system makes professional content displays effortless—whether for workouts, event schedules, or signage needs!** 🚀
